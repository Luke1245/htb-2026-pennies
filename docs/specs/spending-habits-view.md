# Spending habits view

The Spending habits screen shows the live Financial portrait. It opens from the dashboard's Spending insights tile and keeps the Category breakdown on the dashboard.

- Show a short reading, a few Spending habits, Projected habits, Education, and Suggestions. The copy teaches one lesson in plain language.
- Load the stored reading when the screen opens. Build one when it is missing and there is an ordinary Transaction or logged Subscription.
- A new ordinary Transaction replaces the portrait. A failed update keeps the previous reading and can be retried.
- Changing sharing mode warns that the portrait will be removed and written again. Sanitised mode explains that protected details may make the reading less specific.
- With no spending history, direct the user to add a Transaction. Do not invent a portrait.
